## 5. GitHub Usage Guidelines

The assigned intern must:

1. Use this repository for all project-related source-code changes.
2. Use meaningful commit messages.
3. Keep the repository organized.
4. Test changes before pushing.
5. Use development branches for significant features or changes.
6. Keep the `main` branch stable.
7. Create Pull Requests when required.
8. Keep relevant documentation updated.
9. Avoid unnecessary files and dependencies.
10. Do not delete or modify project history unnecessarily.


## 6. Security & Confidentiality

This repository is private and belongs to NxtWise IT Pvt. Ltd.

The assigned intern must not:

- Share the repository with unauthorized persons.
- Make company source code publicly available.
- Upload company source code to unauthorized repositories.
- Copy or distribute company project materials without authorization.
- Share repository access with other persons.
- Use another person's GitHub account.


## 7. Credentials & Sensitive Information

NEVER commit sensitive information to this repository.

Do not commit:

- Passwords
- API keys
- Access tokens
- Database credentials
- Private keys
- Service-account credentials
- `.env` files containing secrets
- Cloud credentials
- Confidential company information

Use environment variables and appropriate local configuration
for sensitive values.

If credentials are accidentally committed, immediately notify
the designated NxtWise team.
